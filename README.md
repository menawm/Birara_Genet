# Birara Genet — Website

Official website for Birara Genet Charitable Organization, a vocational training 
organization based in Bole Sub-City, Addis Ababa, Ethiopia.

## About

Birara Genet has been empowering individuals from underserved communities since 2013 
by providing practical vocational training and connecting graduates with stable employment.

**Live site:** [biraragenet.org](https://www.biraragenet.org)

## Pages

- Home
- About Us
- Our Programs
- Stories
- Our Ventures
- Donate
- For Donors
- For Employers
- For Volunteers
- For Applicants
- Contact

## Tech Stack

- HTML / CSS / JavaScript
- Single-page application — all pages live in `index.html`
- Hosted on Netlify
- Deployed via GitHub

## Deployment

The site auto-deploys on every push to the `main` branch via Netlify.

To update the site:
1. Edit `index.html`
2. Commit and push to `main`
3. Netlify redeploys automatically within ~30 seconds
